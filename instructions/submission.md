# Coursework: submission guidelines

To submit your coursework through Canvas, prepare and upload a **zip file** named:

`<candidateID>.zip`

where `<candidateID>` is your 6‑digit Sussex candidate number.

The contents of the zip file depend on whether you want to be assessed on the type‑checker.

* If you **do** want to be assessed on the type‑checker, the zip file must contain only:
    * `SimpleLang.g4`
    * `SimpleLangInterpreter.java`
    * `TypeChecker.txt` (described below)

* If you **do not** want to be assessed on the type‑checker, the zip file must contain only:
    * `SimpleLang.g4`
    * `SimpleLangInterpreter.java`

`TypeChecker.txt` is **not assessed**, but it must be included to receive more than 0% for the type‑checker. It must be a plain text file (English), providing a brief, high‑level, informal description (max 100 words) of how the type‑checker is implemented in `SimpleLangInterpreter.java`.

Not following these submission rules (extra files, missing files, wrong structure, etc.) will cost marks as per the marking criteria.

## University rules for e‑submissions through Canvas

* You may submit and **resubmit** your zip file unlimited times **before the deadline**.
* Canvas automatically closes submissions at the deadline; staff cannot reopen it.
* After the deadline:
    * If you submitted before the deadline, your **last pre‑deadline submission** will be marked. Any later uploads are ignored.
    * If you did **not** submit before the deadline, you have **7 days** to make a *late submission*.  
      Late submissions incur penalties (see marking criteria). Only the **first** late submission is marked.

Do **not** wait until the last minute—Canvas often slows down or becomes unreliable near deadlines. Submit early.

If Canvas issues prevent submission before the deadline, you may consider submitting an e‑submission error form:  
https://www.sussex.ac.uk/ei/internal/forstudents/courseworksupport  
Note that you may use this process **only once per academic year**.
