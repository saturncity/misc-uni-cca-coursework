The program has a two phased approach. It first runs a separate type check of the entire program before interpretation begins. First, it checks function declarations and makes sure that there are no invalid function signatures (correct parameter types and no duplicates). Then it checks the essential semantic constraints like having a main function that returns a valid type, and has valid args. Finally it checks each function body by creating a type environment mapping variables to types, then recursively inferring expression types while validating operator requirements and ensuring that each function body matches its declared return type.
